    Drop two photos, or tap to choose. Each photo is analysed and turned into an embedding; the two are compared with cosine similarity.

    What happens to a face

    Nothing here is a black box: four steps, measured results on people the model never saw, and the limits.

    1DetectYuNet finds the face and 5 landmarks.
    2AlignA similarity transform maps the landmarks to the standard 112×112 template.
    3EmbedA ResNet turns the crop into a 512-number, unit-length vector.
    4CompareCosine similarity of two vectors; a match if it is above the threshold.

    Evidence

    Please read: limits & privacy

    • No liveness check. A printed photo or a screen can fool any system built only on face embeddings. Do not use this to protect anything.
    • Strict threshold on purpose. It is set for a 0.1% false-accept rate, so it will sometimes reject the real person in poor light or at odd angles. Enrolling in a few poses helps.
    • Accuracy varies with lighting, pose, age and demographics; the training data (celebrity photos and synthetic faces) is not balanced.
    • Privacy. The server keeps nothing — frames are processed in memory and discarded. Enrolled embeddings are stored in your browser’s local storage only; “Delete all” removes them.
    • Licence. The weights were pre-trained on DigiFace-1M, which is research-use only, so this demo is non-commercial.
